# 숨결섬 UI 디자인 기준

## 컨셉

바닷가 생활 수첩과 여행 가방. 다른 생활 게임의 읽기 순서와 인벤토리 관습을 참고할 수 있지만, 그래픽은 프로젝트에서 직접 그린다. 탐험의 시야를 비우고 물건을 꺼내는 과정에 생활감을 둔다.

## 시각 구성

- 제목·행동 버튼: Gaegu Bold. 본문·설명: Gowun Dodum Regular. 한글과 영문을 같은 서체군으로 제공하며 Unity 기본 폰트로 대체하지 않는다.
- 종이: 따뜻한 모래색. 글자와 가방 안감: 깊은 청록. 선택 탭: 바닷빛. 주요 행동: 산호색.
- 가방 손잡이·공통 표지·박음질·물결은 자체 벡터 그래픽이다. 아이템 21종은 제공된 모델·재질을 렌더한 PNG를 사용한다. 외부 UI 이미지나 이모지를 아이템 아이콘으로 사용하지 않는다.
- 사용자 시안 피드백: 기본 UI 방향 유지, 버튼의 개성을 강화. 버튼에 접힌 종이 모서리·박음질·손그림 화살표·손글씨를 적용했다. 포인터를 올리면 약간 커지고 누르면 눌리며, 레이아웃 공간은 유지한다.
- 인벤토리: 왼쪽 분류·아이템 격자, 오른쪽 상세와 행동, 하단 생활 날짜. 잠긴 무기는 잠금 아이콘과 기존 해금 조건을 표시한다.
- 화면 열림은 0.14초 페이드. 재사용 중인 버튼은 매 프레임 껐다 켜지 않아 포커스·누름 상태를 유지한다.

## Unity 구현

- `Resources/UI/Screens`의 화면 프리팹과 `Resources/UI/Elements/NotebookElement.prefab`를 사용한다.
- `NotebookSurface`는 uGUI 노드를 재사용하며 각 화면이 선언한 배치·텍스트·명령을 표시한다. `NotebookGraphic`, `IslandIcon`, `NotebookButtonMotion`은 표현만 담당한다.
- CanvasScaler 기준 1600×900, Expand. 넓은 화면은 남는 공간을 확장하며 패널의 종횡비를 늘리지 않는다.
- 모든 사용자 표시 문구는 Localization 테이블을 조회한다. 동적 숫자와 격자 좌표만 코드에서 조합한다.
- 서체는 OFL 원문과 함께 `Resources/UI/Fonts`에 포함했다. 출처는 THIRD_PARTY_ASSETS.md에 기록한다.

## 조작

필드 커서 고정·마우스 시점, 좌클릭으로 손에 든 도구/무기 사용, R 무기 스킬. I로 가방을 열면 필드 입력을 차단하고 커서를 해제한다. 도구 사용은 자유지만 채집 판정은 전방 2.3m 이내 지정 대상에만 적용한다. 허공·잘못된 도구·소진 대상에서 자원을 지급하지 않는다. 가방 닫기 직후 두 프레임은 필드 사용을 받지 않는다.
