## 기존 설명에서 발견한 정합성 확인 사항

- 기존 Notion과 README의 `Documentation/PORTFOLIO.md` 링크 대상은 현재 로컬 HEAD에 없다. 원격 링크가 깨졌다고 단정하지 않고 게시 전 확인한다. 새 문서로 임의 연결하거나 기존 기록을 삭제하지 않는다.
- README에는 저장 버전 v4 문장이 남아 있지만 현재 GameSaveData.CurrentVersion은 5이고 기존 Notion도 v5로 설명한다. 최신 설명은 v5 기준이다. 이번 비주얼 변경으로 저장 버전을 새로 올린 것은 아니다.
- 직업 전환 로직은 이미 존재했다. 이번 변경의 성과는 직업을 구분하는 외형·공격·효과 표시 연결이다.
- 무기 스킨과 캐릭터 의상은 별개다. 일반·특수 무기는 직업 의상을 공유하고 특수 무기는 별도 무기 형상과 스킬 VFX로 구별한다.
- 최신 Fishing-Hud 이미지는 작은 해상도의 검증용 캡처다. 화면 가독성 대표 이미지로 크게 확대하지 않는다.
