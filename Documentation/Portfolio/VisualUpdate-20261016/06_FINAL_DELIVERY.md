사용할 폴더는 **FinalCapture**다. 이전 45초 초안은 최종본으로 사용하지 않는다.

## 결과물

- `FinalCapture/breath-island-portfolio-final.mp4`: 전체 소개 75초, 1280×720, 60fps, 무음.
- `FinalCapture/breath-island-life.mp4`: 이동·점프·실내 상호작용 30초, 60fps.

영상 상단의 자동 연출 표시는 사용자 요청으로 제거했다. 화면 하단에는 구간 시작 2초 동안 내용만 표시한다. 최종 편집 시 아래 촬영 방식은 영상 설명 또는 프로젝트 본문에 남긴다.

## 촬영 방식과 사실 범위

Unity 6000.5.4f1 Editor Play Mode에서 실제 게임 코드·모델·애니메이션을 60fps로 렌더링했다. 촬영 카메라와 명령은 테스트가 제어한다. 이동·점프는 가상 키보드 입력을 실제 ThirdPersonMotor에 전달한다. 가구 사용·보관·휴식은 실제 기능 시스템의 거리·대상·수량 규칙을 통과한다. Windows 직접 조작 녹화나 연속 플레이 영상으로 소개하지 않는다.

기존 시연 데이터와 별도 임시 저장 경로를 사용했다. 특수 무기는 촬영 데이터에서 해금했다. 장면 사이의 촬영 위치 변경은 컷으로 구분하며 이동 과정처럼 보여 주지 않는다. 의자에 접근하는 장면과 부두 이동은 실제 이동 처리다. UI 버튼 클릭을 녹화한 것은 아니며 보관·휴식 명령은 촬영 코드가 호출한다.

게임 기준 커밋은 `ec53ea9`다. 이번 변경은 촬영 테스트·편집 도구·자료에 한정한다. 사용자 저장, 일반 게임 지급량, 해금 조건, 게임 런타임 코드는 바꾸지 않았다. 기존 실내 Windows 직접 플레이 영상은 별도로 보존한다. Notion은 수정하지 않는다.

## 수정한 촬영 문제

- 기존 27.33초의 카메라 위치·방향 즉시 전환을 제거했다. 세 무기 장면은 각 구간 내 고정 구도다.
- 전체 프레임을 30fps에서 60fps로 재촬영했다. 프레임 보간으로 만든 60fps가 아니다.
- 장면 사이에는 짧은 페이드를 넣어 컷을 구분했다.
- 무기 촬영 전 실제 접지 처리를 거친다. 이동 컴포넌트를 바로 중지해 생길 수 있는 촬영용 공중 상태를 방지한다.
- 실내 카메라를 조정해 앉은 캐릭터가 앞쪽에서 보이도록 했다. 렌더 타깃을 촬영 구간 동안 유지해 UI 해상도 계산이 작은 Editor 창 크기에 의존하지 않도록 보완했다.

## 검증 범위

촬영 테스트는 이동 거리, 점프 높이와 착지, 의자·상자·침대 대상 선택, 앉기·일어나기, 자원 이동 수량, 휴식 후 날짜 증가를 검사한다. 전체 회귀 테스트와 Windows 빌드는 이 자료 작업에서 다시 실행하지 않았다. 전체 디코딩·프레임 수·프레임 변화 검사와 장면별 화면 검토 결과는 `FinalCapture/review.json`에 기록한다. 영상 재생 기기별 성능이나 게임 전체의 모든 동작이 검증됐다는 뜻은 아니다.

외부 모델·애니메이션·VFX와 AI 지원 구현의 기여 구분은 `00_CLAUDE_HANDOFF.md`를 따른다. 이미지 합성으로 가림·장비·동작을 꾸미지 않는다.
