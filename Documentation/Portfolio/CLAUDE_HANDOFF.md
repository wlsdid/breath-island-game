# Notion 정리용 전달 자료

2026-10-12 사용자 요청: Notion 파일은 Codex가 수정하지 않는다. 아래 자료를 참고하여 Claude가 기존 「숨결섬 — 낚시와 섬 생활 게임」 페이지를 정리한다. 기존 슬라이드·이미지·제작 기록과 공개 범위를 보존한다.

## 반영할 최신 결과

- [프로젝트 소개](../PORTFOLIO.md): 게임 개요, 본인 역할, 문제 해결 사례 3개와 코드·테스트 근거.
- [실내 실제 플레이 영상](Video/breath-island-indoor-demo.mp4): 3분 56초, Windows 실행 파일의 제작·회전 배치·집 편집·저장 복원. 합성 시연 저장 사용. 재실행은 별도 촬영 구간으로 표시.
- 바다·채집 영상은 사용자 요청으로 제외했다. 영상에 없는 장면을 포함한다고 설명하지 않는다.
- 본인 역할: 기획, 디자인 방향과 판단, 직접 플레이 검수. AI 지원: 코드 구현, 자동 검증, 문서·영상 편집. 직접 작성하지 않은 코드를 본인 단독 구현으로 소개하지 않는다.
- 대표 이미지 6장은 기존 Editor Play Mode 렌더이며 Windows 영상과 출처를 구분한다.

## 확인된 사실

- 수정한 Windows 낚시 화면에서 플레이어 몸체 가림 제거 확인. 직접 입력으로 포획 후 판매: 72→90코인, 포획 1회, glimmer 도감 등록을 격리 저장에서 확인.
- 도끼 선택 후 직접 채집: 나무 30→33, 채집 1회, tree_a 소진 기록.
- 의자 제작: 나무 30→27, 의자 재고 1→2. (6,2)에 90도 회전 배치하여 배치 가구 9→10.
- 집 내부 벽 미리보기 중 원본 저장 유지, 취소 후 복원. 적용 시 나무 27→26, 벽 1개 저장.
- 자동 저장과 수동 슬롯 1에 동일 결과 확인. 재실행한 실내에서 의자·벽 복원 확인. 별도 촬영에서 슬롯 1 불러오기 메시지와 이동 확인.
- 테스트: 전체 Edit 98/98, 전체 Play 32/32 이후 관련 UI 7/7, 몸체 가림 수정 후 회귀 11/11. 33개 전체를 한 번에 재실행한 결과로 쓰지 않는다. Windows Mono 빌드 성공.

## 남은 한계

실물 게임패드, Windows 전체 핵심 루프·모든 화면 비율/언어·수동 슬롯 2/3의 최신 직접 조작은 이번 작업에서 확인하지 않았다. 자동 테스트와 과거 사용자 확인을 이번 Windows 검증으로 합치지 않는다. 자동화 키 입력이 반영되지 않아 사용자가 직접 입력한 부분이 있다. 초기 GDI 녹화는 화면이 정지되어 최종 영상에서 제외했다.

자세한 근거는 [VALIDATION.md](../VALIDATION.md), [evidence.json](evidence.json), [시연 가이드](DEMO.md)를 따른다. 최신 Notion 편집은 수행하지 않았으므로 기존 페이지에는 이전 상태가 남아 있을 수 있다.
