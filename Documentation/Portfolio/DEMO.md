# 포트폴리오 시연

## 실행

프로젝트 루트에서 `./Build-BreathIsland.ps1`로 테스트·Windows Mono 빌드를 만든 후 `./Play-Portfolio.ps1`을 실행한다. `-Scene sea`, `-Scene gather`, `-Scene home`으로 시작 장면을 고를 수 있다. 기본은 마을이다.

매 실행은 Builds/Portfolio/Sessions 아래 새로운 격리 경로를 만든다. 일반 사용자 저장은 읽거나 덮어쓰지 않는다. 화면이 필요 없는 준비는 `-PrepareOnly`를 사용한다. 같은 시연을 종료·재실행할 때는 출력된 경로의 **Resume.cmd**를 실행한다. 새 실행기는 기존 시연을 덮어쓰지 않는다.

자동 저장은 현재 시작점, 수동 슬롯 1은 바다, 2는 채집, 3은 실내다. 수동 저장하면 해당 시연 슬롯 내용은 바뀐다. 슬롯 이동은 Esc 메뉴에서 불러오기를 사용한다. F5/F9는 슬롯 1 저장/불러오기다.

## 시연 데이터 공개

나무 30·돌 8·약초 2, 배치 가구 9개, 미배치 의자·조명 각 1개를 준비한 합성 저장이다. 장비 해금·숙련도·누적 채집·제작 업적은 부여하지 않는다. 일반 새 게임 보상·비용·해금 조건은 그대로다. Seeds의 JSON은 실제 사용자 저장이 아니다.

## 3~5분 영상 구성

| 구간 | 조작과 설명 | 시간 목표 |
|---|---|---|
| 도입 | 마을, 게임 이름과 본인 역할·AI 지원 구현 표기 | 15초 |
| 바다 | 슬롯 1 → F → 캐스팅 → Space 감기/S 느슨하게 → 판매 또는 기록 | 60~90초 |
| 장면 전환 | 별도 섬 생활 시연 저장 사용 자막 | 5초 |
| 채집 | 슬롯 2 → I → 도끼 손에 들기 → 나무 전방 좌클릭 3회 → 자원 확인 | 35초 |
| 집 | 슬롯 3 → I → 망치 → 제작 → 의자 배치·회전 | 45초 |
| 편집·복원 | 집 꾸미기 → 집 확장·변형 → 빈 외곽 추가/취소 또는 적용 → 저장·불러오기 | 45초 |
| 마무리 | 구현·검증 범위와 남은 한계 | 15초 |

녹화는 실제 실행 화면을 사용한다. 느린 조작을 잘라낸 구간과 별도 저장 전환을 표시한다. Editor 렌더링이나 정지 이미지를 Windows 직접 플레이 영상으로 소개하지 않는다. 촬영된 파일이 없으면 ‘영상 준비 중’으로 유지한다.

## 이미지 출처

자동 렌더는 PortfolioPresentationTests의 실제 Unity Play Mode 장면에서 얻는다. 카메라를 촬영 구도로 변경한 대표 이미지이며 Windows 직접 조작 증거가 아니다. 원본 출력은 Builds/Portfolio/Images, 검토한 공개용 사본은 이 폴더의 Images에 둔다.

새 모델·폰트 다운로드는 하지 않는다. 기존 KayKit·Kenney CC0 모델과 OFL 폰트를 사용한다.
