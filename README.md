# 숨결섬 (가제)

[포트폴리오 소개·문제 해결 사례](Documentation/PORTFOLIO.md) · [격리 시연 실행](Documentation/Portfolio/DEMO.md)

[실내 플레이 영상 · 3분 56초](Documentation/Portfolio/Video/breath-island-indoor-demo.mp4) — 제작·회전 배치·집 편집·저장 복원. 시연용 저장 데이터를 사용했습니다.

기획 · UI 디자인 · 플레이 테스트를 맡고, 구현은 Codex · Claude를 활용했습니다. 현재는 개선 중인 프로토타입입니다.

Unity 6000.5.4f1 기반 3D 섬 생활 게임 프로젝트입니다. 기존 바다 버티컬 슬라이스에 육지 채집, 무기별 직업·숙련도, 도전과제, 가구 제작·집 꾸미기를 연결합니다. 콘텐츠 에셋·Localization·화면 모듈 구조로 분리되어 있습니다.

테스트·Windows 빌드·실행 화면 검증 결과는 [Documentation/VALIDATION.md](Documentation/VALIDATION.md)를 참고하세요.

집과 시설 외관은 Kenney Fantasy Town Kit의 목재·석조·붉은 지붕으로 구성합니다. 광장과 산책길이 부두·시설·주거 구역을 연결하며, 기본 실내는 20×20이며 기존 가구 좌표와 출입 위치를 유지합니다. 가구는 보관 상자를 포함한 9종이고 가방의 가구 탭에서 벽·바닥 마감을 각각 3종 중 무료로 미리보고 적용할 수 있습니다.

## 현재 플레이 범위

낚시는 찌에 입질이 온 뒤 **3초 안에 좌클릭 또는 Space로 챔질**해야 줄 감기가 시작됩니다(패드 A·화면 버튼도 지원). 놓치면 이미 던질 때 사용한 미끼만 소모하고 재시도할 수 있습니다. 줄 감기 Space / 줄 풀기 S는 기존과 같습니다.

2026-10-15 해안·낚시 표현을 보완했습니다. 얕은 물·포말·풀 가장자리와 잔물결을 추가했고, 낚시 중에는 낚싯대 캐스팅·릴 감기·풀기·장력에 따른 휨·찌와 줄·어종별 도약을 표시합니다. 낚시 확률·보상·장력 수치와 저장 형식은 유지합니다. 기존 실내 영상은 이 변경 전 버전입니다.

- 에디터에서 배치한 숲속 판타지 마을 프리팹과 3인칭 캐릭터 이동
- 1인칭 낚시, 5종 일반 어류, 1종 포식자
- 판매·전시·도감·재료 처리
- 조선소·수족관 2단계 성장
- NPC 2명과 누적형 호감도
- 일반 검·활·지팡이와 직업별 숙련도, 도전과제로 해금되는 특수 무기 스킬
- 도끼·곡괭이·맨손 채집, 망치를 사용하는 가구 제작
- 지붕 없는 20×20 실내에서 가구 선택·미리보기·회전·배치·회수
- 소파(나무 8)·수납장(6)·작은 선반(4)·낮은 탁자(3) 제작, 페이지당 4종 제작 목록
- 벽·바닥 마감 선택·적용·취소와 v1~v4 저장을 보존하는 v5 마이그레이션
- 자동 저장 1개, 수동 저장 3개
- 한국어·영어 전환, 키보드·마우스와 Xbox 계열 게임패드

## 실행 및 빌드

Unity Hub에서 Personal 라이선스를 활성화한 뒤 프로젝트를 엽니다.

1. 첫 임포트에서 `LocalizationSetup`이 기존 한국어·영어 테이블을 Unity Localization/Addressables에 등록합니다. 필요하면 `숨결섬 > Localization 설정 검증`을 실행합니다.
2. 기존 `Assets/BreathIsland/Scenes/BeachVerticalSlice.unity`를 열고 Play를 누릅니다. 씬이 없을 때만 `숨결섬 > 플레이 씬 생성`을 사용합니다.
3. `숨결섬 > Windows 검증 빌드 (Mono)`로 `Builds/Windows/BreathIsland.exe`를 생성합니다. 기존 씬은 빌드 중 재생성하지 않습니다.

Localization 설정 등록, Edit Mode·Play Mode 테스트, Windows Mono 배치 빌드:

```powershell
.\Build-BreathIsland.ps1
```

테스트 결과는 `Builds/editmode-results.xml`, `Builds/playmode-results.xml`에 기록됩니다. `-SkipTests`는 테스트를 생략하며 완료 조건 검증용으로 사용하지 않습니다.

MSVC C++ Build Tools와 Windows SDK가 설치된 출시 환경에서는 다음 명령으로 IL2CPP 빌드를 생성합니다.

```powershell
.\Build-BreathIsland.ps1 -ReleaseIl2Cpp
```

## UI

생활 수첩·여행 가방 컨셉의 자체 uGUI입니다. 개구 제목·버튼 서체와 고운돋움 본문, 자체 선화와 제공 모델에서 렌더한 아이콘·박음질·종이 라벨을 사용합니다. 전체 화면은 공통 디자인을 공유하며 자세한 기준은 [UI_DESIGN.md](Documentation/UI_DESIGN.md)에 기록합니다.

## 코드 구조

런타임은 낚시, 포식자 전투, 관계, 시설, 장비, 육지 활동, 집 꾸미기, 표현, 콘텐츠, 현지화, UI, 코어 흐름으로 분리되어 있습니다. `BreathIslandGame`은 기능 객체 조립과 프레임 전달, `GameHud`는 13개 화면의 라우팅을 담당합니다.

- 콘텐츠: `Assets/BreathIsland/Resources/Content/VerticalSlice.asset`에서 기존 어종·NPC·시설 에셋을 참조합니다. 수치와 저장용 ID는 에셋에서 유지합니다.
- 문자열: `Assets/BreathIsland/Localization`의 한국어·영어 Unity String Table에서 편집합니다. 콘텐츠 에셋에는 번역 키를 저장합니다.
- 확장 콘텐츠: `Resources/Content/IslandLife.asset`가 무기·직업·공격·도전과제·채집 지점·가구와 표현 에셋을 참조합니다.
- 저장: JSON 버전 4. v0~v3 필드를 보존하고 장비·숙련도·해금·생활 자원·가구·마감·상자별 보관 데이터를 유지합니다. 자동 1개·수동 3개 슬롯과 백업 정책을 유지하며, 읽기만으로 원본을 수정하지 않습니다.

기존 낚시·포식자 전투·시설 경제 수치는 유지합니다. 농사와 Steamworks는 포함하지 않습니다. 세부 경계는 [Documentation/ARCHITECTURE.md](Documentation/ARCHITECTURE.md)를 참고하세요.

## 기본 조작

- 이동: `WASD` / 왼쪽 스틱. 속도 2.86m/s(기존의 55%). 점프: 탐험·실내에서 `Space` / 게임패드 North.
- 카메라: 필드 커서 고정·마우스 / 오른쪽 스틱. 메뉴에서는 커서를 해제하고 시점 이동을 멈춥니다.
- 상호작용: `E` / 게임패드 South
- 낚시 시작: `F` / 게임패드 South. 낚시 중 캐스팅·감기: `F`, `Space` / 게임패드 South.
- 줄 느슨하게: `S` / 게임패드 East
- 마을 성장: `M`
- 도감: `Tab`
- 수동 저장: `F5`, 불러오기: `F9`
- 언어 변경: `L`
- 메뉴 닫기: `Esc`
- 인벤토리: `I`로 열기·닫기. 전체 가방에서 드래그로 빈칸 이동·자리 교환, 종류별 정리가 가능합니다. 종류별 탭에서 장착·제작·해금 안내를 확인합니다.
- 손에 든 도구 사용·무기 기본 공격: 좌클릭. 특수 무기 스킬: `R`. 훈련 대상 회복: `T`.
- 벌목·채광: 인벤토리에서 도구를 꺼낸 뒤 대상을 바라보고 좌클릭. 맨손 채집·대화·실내 입장은 `E`. 실내 입구는 시작 지점 오른쪽의 작은 바닥 표식입니다.
- 집 꾸미기: 실내에서 인벤토리의 망치 → 만들기. 가구 탭의 보유 가구 → 배치 → 격자 선택·회전·확정. 방 안의 물건 목록에서 회수합니다.

확장 UI는 키보드·마우스 기준입니다. 기존 게임패드 입력은 유지하지만 신규 화면의 게임패드 전용 탐색은 제공하지 않습니다.

## 생활·성장 규칙

- 무기·생활 도구는 시작부터 선택할 수 있습니다. 생활 도구를 선택해도 무기로 정한 직업은 바뀌지 않으며 도구 스킬은 없습니다.
- 일반 무기는 기본 공격만 가능합니다. 가구 3개 제작으로 특수 검, 유효 명중 30회로 특수 활, 나무·돌·약초 각각 3회 채집으로 특수 지팡이가 해금됩니다. 해금 후 장비 화면에서 직접 장착합니다.
- 직업별 유효 명중 10회부터 스킬 피해 +25%, 30회부터 스킬 재사용 시간 -20%. 일반 공격은 성장하지 않습니다. 훈련 대상은 보상을 주지 않으며 `T`로 체력을 회복할 수 있습니다.
- 채집 완료당 나무 3·돌 3·약초 2. 소진 지점은 집의 침대에서 쉬면 다음 날 재생합니다. 휴식은 기존 낚시 시간 진행 규칙과 별도입니다. 나무·바위는 올바른 도구로 3회 타격하고, 약초는 전방에서 E를 3초 유지해 채집합니다.
- 기본 침대 1개를 제공합니다. 가구 제작에는 망치가 필요하며 의자 나무 3, 탁자 나무 5, 침대 나무 8, 조명 나무 2+돌 2를 소모합니다. 회수하면 가구로 돌려받아 재배치할 수 있습니다.
- 기존 코인·재료와 생활 자원은 분리합니다. 집 출입은 야외 위치를 보존하며 출입구·겹침·방 밖에는 가구를 배치할 수 없습니다.

## 격리 검증

테스트는 임시 저장 폴더를 사용합니다. 별도 실행 검증에는 `BREATH_ISLAND_SAVE_ROOT` 환경 변수로 저장 폴더를 지정할 수 있습니다. 지정하지 않은 일반 실행만 기존 사용자 저장 경로를 사용합니다. 콘텐츠 초기 작성 메뉴는 에디터에서 명시적으로 실행하는 도구이며 런타임이나 일반 빌드에서 콘텐츠를 재생성하지 않습니다.

## 집 안 생활

- ‘집 꾸미기 → 집 확장·변형’에서 바닥과 내부 벽을 격자로 추가·철거합니다. 기본 20×20, 최대 편집 범위 32×32이며 미리보기 후 적용하거나 취소합니다.
- 바닥 추가는 나무 2개, 직접 추가한 바닥 철거는 1개 반환합니다. 기본 바닥은 철거해도 자원을 주지 않습니다. 내부 벽은 나무 1개로 설치·회수합니다. 외벽은 바닥 경계를 따라 이동합니다.
- 출입구, 플레이어, 배치 가구와 연결된 통로를 유지해야 합니다. 기존 저장은 집 크기·가구 좌표를 유지한 채 v5로 이전합니다.

- 고정 카메라에서 WASD로 걸으며 가구를 바라보고 E로 사용합니다. 문 앞에서 밖을 바라보고 E를 누르면 야외로 돌아갑니다.
- 의자·소파는 E로 앉고 E 또는 이동 키로 일어납니다. 침대는 확인 후 다음 날 09시까지 쉬며 기존 채집 자원이 재생됩니다.
- 가방에서 가구를 선택하거나 ‘집 꾸미기’를 눌러 기존 격자 배치·회수 화면으로 전환합니다. 메뉴에서는 이동과 가구 사용을 차단합니다.
- 보관 상자는 망치로 나무 5개를 소비해 제작합니다(1×1칸). 각 상자는 16칸이며 자원 탭 물건은 종류별 99개, 미배치 가구는 1개씩 담습니다. 도구·무기는 보관하지 않습니다.
- 상자에서 1개·선택 수량·가능한 만큼 넣고 꺼낼 수 있습니다. 내용물이 남은 상자는 회수할 수 없으며, 제작은 가방 자원만 사용합니다. 보관 이동은 채집 실적을 늘리지 않습니다.
- 앉기·열린 메뉴는 일시 상태입니다. 불러오면 실내의 안전한 위치에서 서 있는 상태로 복원합니다.

새 게임에는 기본 침대 1개를 가방에 제공합니다. 기존 저장도 배치·가방·상자 어디에도 침대가 없으면 한 번 보완합니다. 지급은 제작 실적에 포함하지 않으며 기존 침대 제작 비용은 나무 8개로 유지합니다. 다른 가구에 자원을 모두 써도 침대를 배치해 다음 날로 진행할 수 있습니다.

## NPC·마을 표현 보완 (2026-10-15)

나리·마루를 서로 다른 KayKit 캐릭터 모델과 대기 애니메이션으로 교체하고, 가까이 온 플레이어를 바라보도록 했습니다. 마을에 창틀·차양·화단·벤치·광장 가장자리·굴뚝을 추가했습니다. 기존 NPC 기능과 상호작용 위치는 유지하며 장식에는 새 게임 규칙을 넣지 않았습니다. 10월 12일 포트폴리오 영상은 이전 버전 기록입니다.
