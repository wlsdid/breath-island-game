# 숨결섬 (가제)

Unity 6000.5.4f1 기반 3D 섬 생활 게임 프로젝트입니다. 기존 바다 버티컬 슬라이스에 육지 채집, 무기별 직업·숙련도, 도전과제, 가구 제작·집 꾸미기를 연결합니다. 콘텐츠 에셋·Localization·화면 모듈 구조로 분리되어 있습니다.

테스트·Windows 빌드·실행 화면 검증 결과는 [Documentation/VALIDATION.md](Documentation/VALIDATION.md)를 참고하세요.

## 현재 플레이 범위

- 절차형 로우폴리 해안 마을과 3인칭 캐릭터 이동
- 1인칭 낚시, 5종 일반 어류, 1종 포식자
- 판매·전시·도감·재료 처리
- 조선소·수족관 2단계 성장
- NPC 2명과 누적형 호감도
- 일반 검·활·지팡이와 직업별 숙련도, 도전과제로 해금되는 특수 무기 스킬
- 도끼·곡괭이·맨손 채집, 망치를 사용하는 가구 제작
- 지붕 없는 8×8 실내에서 가구 선택·미리보기·회전·배치·회수
- 자동 저장 1개, 수동 저장 3개
- 한국어·영어 전환, 키보드·마우스와 Xbox 계열 게임패드

## 실행 및 빌드

Unity Hub에서 Personal 라이선스를 활성화한 뒤 프로젝트를 엽니다.

1. 첫 임포트에서 `LocalizationSetup`이 기존 한국어·영어 테이블을 Unity Localization/Addressables에 등록합니다. 필요하면 `숨결섬 > Localization 설정 검증`을 실행합니다.
2. 기존 `Assets/BreathIsland/Scenes/BeachVerticalSlice.unity`를 열고 Play를 누릅니다. 씬이 없을 때만 `숨결섬 > 플레이 씬 생성`을 사용합니다.
3. `숨결섬 > Windows 검증 빌드 (Mono)`로 `Builds/Windows/BreathIsland.exe`를 생성합니다. 기존 씬은 빌드 중 재생성하지 않습니다.

Localization 설정 등록, Edit Mode·Play Mode 테스트, Windows Mono 배치 빌드:

```powershell
.\Build-BreathIsland.ps1
```

테스트 결과는 `Builds/editmode-results.xml`, `Builds/playmode-results.xml`에 기록됩니다. `-SkipTests`는 테스트를 생략하며 완료 조건 검증용으로 사용하지 않습니다.

MSVC C++ Build Tools와 Windows SDK가 설치된 출시 환경에서는 다음 명령으로 IL2CPP 빌드를 생성합니다.

```powershell
.\Build-BreathIsland.ps1 -ReleaseIl2Cpp
```

## 코드 구조

런타임은 낚시, 포식자 전투, 관계, 시설, 장비, 육지 활동, 집 꾸미기, 표현, 콘텐츠, 현지화, UI, 코어 흐름으로 분리되어 있습니다. `BreathIslandGame`은 기능 객체 조립과 프레임 전달, `GameHud`는 10개 화면의 라우팅을 담당합니다.

- 콘텐츠: `Assets/BreathIsland/Resources/Content/VerticalSlice.asset`에서 기존 어종·NPC·시설 에셋을 참조합니다. 수치와 저장용 ID는 에셋에서 유지합니다.
- 문자열: `Assets/BreathIsland/Localization`의 한국어·영어 Unity String Table에서 편집합니다. 콘텐츠 에셋에는 번역 키를 저장합니다.
- 확장 콘텐츠: `Resources/Content/IslandLife.asset`가 무기·직업·공격·도전과제·채집 지점·가구와 표현 에셋을 참조합니다.
- 저장: JSON 버전 2. v0/v1 필드를 보존하고 장비·숙련도·해금·생활 자원·가구 데이터를 추가합니다. 자동 1개·수동 3개 슬롯과 백업 정책을 유지하며, 읽기만으로 원본을 수정하지 않습니다.

기존 낚시·포식자 전투·시설 경제 수치는 유지합니다. 농사, 주택 외관·지붕, Steamworks는 포함하지 않습니다. 세부 경계는 [Documentation/ARCHITECTURE.md](Documentation/ARCHITECTURE.md)를 참고하세요.

## 기본 조작

- 이동: `WASD` / 왼쪽 스틱
- 카메라: 마우스 / 오른쪽 스틱
- 상호작용: `E` / 게임패드 South
- 낚시 시작·캐스팅·감기: `F`, `Space` / 게임패드 South
- 줄 느슨하게: `S` / 게임패드 East
- 마을 성장: `M`
- 도감: `Tab`
- 수동 저장: `F5`, 불러오기: `F9`
- 언어 변경: `L`
- 메뉴 닫기: `Esc`
- 장비·도구: `I` 또는 탐험 화면 버튼
- 육지 기본 공격: `Q`, 특수 무기 스킬: `R` (섬 중앙 훈련 대상 근처)
- 채집·실내 입장: 대상 근처에서 `E` 또는 화면 버튼. 실내 입구는 시작 지점 오른쪽의 작은 바닥 표식입니다.
- 집 꾸미기: 제작 → 보유 가구 선택 → 오른쪽 격자 클릭 → 회전 → 배치 확정. 배치 목록을 누르면 회수합니다.

확장 UI는 키보드·마우스 기준입니다. 기존 게임패드 입력은 유지하지만 신규 화면의 게임패드 전용 탐색은 제공하지 않습니다.

## 생활·성장 규칙

- 무기·생활 도구는 시작부터 선택할 수 있습니다. 생활 도구를 선택해도 무기로 정한 직업은 바뀌지 않으며 도구 스킬은 없습니다.
- 일반 무기는 기본 공격만 가능합니다. 가구 3개 제작으로 특수 검, 유효 명중 30회로 특수 활, 나무·돌·약초 각각 3회 채집으로 특수 지팡이가 해금됩니다. 해금 후 장비 화면에서 직접 장착합니다.
- 직업별 유효 명중 10회부터 스킬 피해 +25%, 30회부터 스킬 재사용 시간 -20%. 일반 공격은 성장하지 않습니다. 훈련 대상은 보상을 주지 않으며 화면 버튼으로 체력을 회복할 수 있습니다.
- 채집 1회당 나무 3·돌 3·약초 2. 소진 지점은 집에서 ‘하루 쉬기’를 누르면 다음 날 재생합니다. 휴식은 기존 낚시 시간 진행 규칙과 별도입니다.
- 가구는 기본 지급하지 않습니다. 망치가 필요하며 의자 나무 3, 탁자 나무 5, 침대 나무 8, 조명 나무 2+돌 2를 소모합니다. 회수하면 가구로 돌려받아 재배치할 수 있습니다.
- 기존 코인·재료와 생활 자원은 분리합니다. 집 출입은 야외 위치를 보존하며 출입구·겹침·방 밖에는 가구를 배치할 수 없습니다.

## 격리 검증

테스트는 임시 저장 폴더를 사용합니다. 별도 실행 검증에는 `BREATH_ISLAND_SAVE_ROOT` 환경 변수로 저장 폴더를 지정할 수 있습니다. 지정하지 않은 일반 실행만 기존 사용자 저장 경로를 사용합니다. 콘텐츠 초기 작성 메뉴는 에디터에서 명시적으로 실행하는 도구이며 런타임이나 일반 빌드에서 콘텐츠를 재생성하지 않습니다.
