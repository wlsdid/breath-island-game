# 숨결섬 (가제)

Unity 6000.5.4f1 기반 상용 3D 힐링 낚시 게임 프로젝트입니다. 현재 구현은 첫 달 버티컬 슬라이스 범위입니다.

## 현재 플레이 범위

- 절차형 로우폴리 해안 마을과 3인칭 캐릭터 이동
- 1인칭 낚시, 5종 일반 어류, 1종 포식자
- 판매·전시·도감·재료 처리
- 조선소·수족관 2단계 성장
- NPC 2명과 누적형 호감도
- 자동 저장 1개, 수동 저장 3개
- 한국어·영어 전환, 키보드·마우스와 Xbox 계열 게임패드

## 실행 및 빌드

Unity Hub에서 Personal 라이선스를 활성화한 뒤 프로젝트를 엽니다.

현재 이 컴퓨터의 Unity Editor는 설치되어 있지만 활성 라이선스가 없어 자동 컴파일과 Windows 빌드는 라이선스 활성화 이후에 가능합니다.

1. `숨결섬 > 플레이 씬 생성`으로 `Assets/BreathIsland/Scenes/BeachVerticalSlice.unity`를 생성합니다.
2. 생성된 씬을 열고 Play를 누릅니다.
3. `숨결섬 > Windows 빌드`로 `Builds/Windows/BreathIsland.exe`를 생성합니다.

배치 빌드:

```powershell
.\Build-BreathIsland.ps1
```

## 기본 조작

- 이동: `WASD` / 왼쪽 스틱
- 카메라: 마우스 / 오른쪽 스틱
- 상호작용: `E` / 게임패드 South
- 낚시 시작·캐스팅·감기: `F`, `Space` / 게임패드 South
- 줄 느슨하게: `S` / 게임패드 East
- 마을 성장: `M`
- 도감: `Tab`
- 수동 저장: `F5`, 불러오기: `F9`
- 언어 변경: `L`
- 메뉴 닫기: `Esc`
